## 关于我

我是 **子圭时安 / Alexi Shi**，一个长期探索 **AIGC × 产品 × 设计 × 工程** 的 00 后连续创业者。

我喜欢把想法做成产品，把产品做成系统，再把系统变成可以持续生长的作品。
现在主要关注 **Code Agent、多 Agent 协作、Agentic Engineering、AI 原生软件工作台**。

> 让劳作归于算法，让灵魂奔向星辰。

## MxinspireX 的产品方向

<table>
  <tr>
    <td width="25%">
      <h3>Code Agent</h3>
      <p>围绕真实工程任务执行代码生成、修改、调试、测试与交付。</p>
    </td>
    <td width="25%">
      <h3>Multi-Agent Team</h3>
      <p>通过 Planner、Builder、Reviewer 等角色拆分任务，让 Agent 像一个小团队一样协作。</p>
    </td>
    <td width="25%">
      <h3>Runtime View</h3>
      <p>展示任务状态、执行过程、文件变化、产物与风险，让 AI 工作过程可观察。</p>
    </td>
    <td width="25%">
      <h3>Skill System</h3>
      <p>用 Skills、Knowledge 和工具调用沉淀能力，让工作流可以复用和扩展。</p>
    </td>
  </tr>
</table>
